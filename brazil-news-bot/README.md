## Свободный ввод (живость)

Борис понимает обычные сообщения и живо отвечает (по-русски и по-португальски):

- «Что ты умеешь?», «Кто ты?», «Расскажи о себе» → рассказ о себе и функциях + кнопки
- «Привет», «Добрый день» → живое приветствие, обращается по имени
- «Как дела?», «Как настроение?» → живо отвечает
- «Спасибо», «Круто», «Молодец» → благодарит
- «Пока», «До встречи» → прощается

Не распознанное сообщение → интерактивное приветствие-меню со всеми действиями.

## Важные особенности архитектуры

1. **Сон сервера:** galaxy-приложение засыпает через 60 минут простоя. Пока спит — бот не отвечает. Webhook НЕ решает (спящий сервер не получит событие). Сон отключить нельзя (`GALAXY_APP_USE_GALAXY_ROUTE`). Единственный способ отвечать всегда — перенос на отдельный сервер (VM).
2. **Утренний дайджест:** сервер просыпается по расписанию в 09:00 Мск Пн-Пт. Приложение стартует и в будний день сразу отправляет дайджест (без привязки к узкому окну времени — см. ниже).
3. **Персистентные настройки:** сохраняются в `/data/settings.json` (постоянный том). `loadSettings()` объединяет дефолтные темы с сохранёнными (новые дефолтные темы добавляются).
4. **Клавиатура:** плоский массив кнопок с `DISPLAY: "LINE"` (НЕ вложенные массивы — иначе 422 BITRIX_ERROR).

## Утренний дайджест

Сервер просыпается по расписанию в 09:00 Мск Пн-Пт. При старте в будний день (Мск) приложение сразу отправляет утренний дайджест пользователю — без привязки к узкому окну времени. Это надёжно, потому что сервер и так просыпается только по расписанию: не нужно полагаться на точное время старта контейнера.
